驅動程式 - Linux Device Driver(LDD) - Falco - Build plugins/k8saudit


參考資訊：
https://falco.org/blog/choosing-a-driver/

步驟如下： 

$ go version
    go version go1.21.0 linux/amd64

$ cd
$ git clone https://github.com/falcosecurity/plugins
$ cd plugins/plugins/k8saudit
$ make
$ sudo cp libk8saudit.so /usr/share/falco/plugins/libk8saudit.so

P.S. 必須確保Golang版本大於1.16
