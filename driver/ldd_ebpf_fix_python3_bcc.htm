驅動程式 - Linux Device Driver(LDD) - eBPF - 解決Cannot import name BPF from bcc問題


參考資訊：
https://github.com/iovisor/bcc/issues/2278

問題如下： 

Traceback (most recent call last):
  File "/home/steward/main.py", line 2, in <module>
    from bcc import BPF
ImportError: cannot import name 'BPF' from 'bcc' (/usr/local/lib/python3.9/dist-packages/bcc/__init__.py)

解法如下： 

$ sudo pip3 uninstall bcc
