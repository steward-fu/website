問題如下： 

:: Import PGP key 77193F152BDBE6A6, "Arch Linux ARM Build System <builder+xu3@archlinuxarm.org>"? [Y/n]

解法如下： 

# ls /usr/share/pacman/keyrings/
    archlinuxarm.gpg archlinuxarm-revoked archlinuxarm-trusted

# pacman-key --init
# pacman-key --populate archlinuxarm
