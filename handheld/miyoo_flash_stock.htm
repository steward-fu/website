掌機 - Miyoo - 燒錄原廠韌體


步驟如下：
1. 請先修復USB問題
2. SPI Flash(Pin2接地)
3. 不要插入MicroSD
4. 連接USB至PC
5. SPI Flash(Pin2不接地)
6. 執行如下指令： 

$ cd
$ wget https://github.com/steward-fu/website/releases/download/miyoo/env_spi_stock_v1.7z
$ 7za x env_spi_stock_v1.7z

$ wget https://github.com/steward-fu/website/releases/download/miyoo/env_devel.zip
$ unzip env_devel.zip -d devel

$ cd devel
$ chmod a+x ./sunxi-fel
$ sudo ./sunxi-fel -p spiflash-write 0 ../miyoo_stock_v1.bin
