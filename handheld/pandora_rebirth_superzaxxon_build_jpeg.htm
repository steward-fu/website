掌機 - Pandora(Rebirth) - SuperZaxxon - Build libjpeg-turbo


參考資訊：
https://github.com/libjpeg-turbo/libjpeg-turbo/releases

步驟如下： 

$ cd
$ wget https://github.com/libjpeg-turbo/libjpeg-turbo/releases/download/3.1.3/libjpeg-turbo-3.1.3.tar.gz
$ tar xvf libjpeg-turbo-3.1.3.tar.gz
$ mkdir libjpeg-turbo-3.1.3/build
$ cd libjpeg-turbo-3.1.3/build
$ cmake -DCMAKE_INSTALL_PREFIX=/usr ..
$ make
$ sudo make install
