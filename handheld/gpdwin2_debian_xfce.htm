掌機 - GPD Win2 - Debian 9.0 - 安裝系統(XFCE)


安裝方式：
1. 下載Debian 9.0 DVD
2. 設定USB開機(開機按下Delete進入BIOS)


3. 開始安裝



4. 選擇XFCE


5. 完成


6. 設定螢幕旋轉方向


7. 設定DPI


8. 其它設定 

$ cd
$ wget https://github.com/steward-fu/gpdwin2/releases/download/v1.0/util.7z
$ 7za x util.7z
$ cd gpdwin2_util
$ sudo ./run.sh
$ sudo reboot

完成
