掌機 - M22Pro - 如何Dump SPI Flash(xfel)


1. 進入燒錄模式
2. 執行下命令 

$ xfel sid
    5d40b20048044c14d90001081a5c4dd5

$ xfel version
    AWUSBFEX ID=0x00185900(R528/T113) dflag=0x44 dlength=0x08 scratchpad=0x00045000

$ xfel spinor read 0 $((16*1024*1024)) dump_spi.bin
    100% [================================================] 16.000 MB, 576.270 KB/s
