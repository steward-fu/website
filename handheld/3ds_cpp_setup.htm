$ sudo apt-get install docker* container* -y

$ cd
$ git clone https://github.com/morgenman/nds-docker
$ cd nds-docker

模擬器則是使用citra-emu，由於司徒目前還是使用Debian 10(x64)，因此，需要手動編譯安裝新版ffmpeg，安裝步驟如下： 

$ cd
$ wget https://ffmpeg.org/releases/ffmpeg-3.4.12.tar.xz
$ xz -d ffmpeg-3.4.12.tar.xz
$ tar xvf ffmpeg-3.4.12.tar.xz
$ cd ffmpeg-3.4.12
$ ./configure --enable-shared
$ make -j4
$ sudo make install
$ sudo ldconfig

$ cd
$ wget https://github.com/steward-fu/website/releases/download/3ds/bin_citra-linux-20200627-61f0e52.7z
$ 7za x bin_citra-linux-20200627-61f0e52.7z
$ sudo cp -a canary/* /usr/local/bin/
$ citra-qt
