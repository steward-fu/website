掌機 - FC3000 - Build U-Boot


參考資料：
https://github.com/steward-fu/website/releases/tag/miyoo
https://github.com/steward-fu/website/releases/tag/fc3000

$ cd
$ wget https://github.com/steward-fu/website/releases/download/miyoo/env_toolchain.7z
$ 7za x env_toolchain.7z
$ sudo mv miyoo /opt/
$ export PATH=$PATH:/opt/miyoo/bin

$ wget https://github.com/steward-fu/website/releases/download/fc3000/uboot.tar.gz
$ tar xvf uboot.tar.gz
$ cd uboot
$ ./run.sh /dev/sdX fc3000
