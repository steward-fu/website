掌機 - Z-Pocket Game Pro (ZPG Pro) - 解決Error: Libtool library used but LIBTOOL is undefined問題


問題如下： 

Makefile.am:120: error: Libtool library used but 'LIBTOOL' is undefined
Makefile.am:120:   The usual way to define 'LIBTOOL' is to add 'LT_INIT'
Makefile.am:120:   to 'configure.ac' and run 'aclocal' and 'autoconf' again.
Makefile.am:120:   If 'LT_INIT' is in 'configure.ac', make sure
Makefile.am:120:   its definition is in aclocal's search path.

解法如下： 

$ sudo apt-get install libtool -y
