掌機 - GPD Win 上蓋鋁合金版 - Debian 9.0 - Build Kernel 4.18.0


Kernel 4.18.0修復音效、MicroSD卡以及電池等問題，建議大家手動升級，編譯步驟如下： 

$ sudo apt-get install kernel-package

$ cd
$ wget https://github.com/torvalds/linux/archive/v4.18.tar.gz
$ tar xvf v4.18.tar.gz
$ cd linux-4.18
$ make-kpkg clean
$ fakeroot make-kpkg --initrd --revision=0.0.1 kernel_image kernel_headers

P.S. 記得刪除/lib/modules/4.18.0/kernel/sound/x86/snd-hdmi-lpe-audio.ko檔案，因為這個Driver會導致Null Pointer Exception，變成無法正常開、關機和重啟
