掌機 - RGB10 - Build Recovery


參考資訊：
https://wiki.odroid.com/odroid_go_advance/recovery_spirom

步驟如下： 

$ sudo apt-get update
$ sudo apt-get install -y git lzop build-essential gcc bc libncurses5-dev libc6-i386 lib32stdc++6 zlib1g:i386 -y

$ cd
$ wget https://releases.linaro.org/components/toolchain/binaries/6.3-2017.05/aarch64-linux-gnu/gcc-linaro-6.3.1-2017.05-x86_64_aarch64-linux-gnu.tar.xz
$ tar xvf gcc-linaro-6.3.1-2017.05-x86_64_aarch64-linux-gnu.tar.xz
$ sudo mv gcc-linaro-6.3.1-2017.05-x86_64_aarch64-linux-gnu /opt/rgb10

$ export ARCH=arm64
$ export CROSS_COMPILE=aarch64-linux-gnu-
$ export PATH=/opt/rgb10/bin/:$PATH

$ git clone https://github.com/hardkernel/u-boot.git -b odroidgoA-v2017.09
$ cd u-boot
$ make distclean
$ ./make.sh odroidgo2-spi
$ ./build_recovery.sh

燒錄到MicroSD 

$ cd sd_fuse
$ sudo dd if=sd_fuse/sdcard_recovery.img of=sdx conv=fsync

P.S. 接著使用這張MicroSD開機就可以刷入Recovery
