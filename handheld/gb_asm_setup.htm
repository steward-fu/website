Build rgbds 

$ cd
$ git clone https://github.com/gbdev/rgbds
$ cd rgbds
$ make
$ sudo make install

Build gambatte 

$ cd
$ git clone https://github.com/sinamas/gambatte
$ cd gambatte
$ ./build_sdl.sh
$ sudo cp gambatte_sdl/gambatte_sdl /usr/bin/
