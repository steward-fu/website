掌機 - Z-Pocket Game Pro (ZPG Pro) - Build Kernel


步驟如下： 

$ cd
$ wget https://releases.linaro.org/components/toolchain/binaries/6.3-2017.05/aarch64-linux-gnu/gcc-linaro-6.3.1-2017.05-x86_64_aarch64-linux-gnu.tar.xz
$ tar xvf gcc-linaro-6.3.1-2017.05-x86_64_aarch64-linux-gnu.tar.xz
$ sudo mv gcc-linaro-6.3.1-2017.05-x86_64_aarch64-linux-gnu /opt/zpg-linaro
$ export PATH=$PATH:/opt/zpg-linaro/bin

$ wget https://github.com/steward-fu/website/releases/download/zpg-pro/kernel.tar.gz
$ tar xvf kernel.tar.gz
$ cd linux
$ ARCH=arm64 make marsboard_defconfig
$ ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- make -j8
