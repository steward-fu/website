家用機 - Play Station - Build img2tim


參考資訊：
https://github.com/Lameguy64/img2tim

$ cd
$ git clone https://github.com/Lameguy64/img2tim --recursive
$ cd img2tim
$ g++ *.cpp -o img2tim -lfreeimage
$ sudo cp img2tim /usr/local/bin
$ img2tim --version
