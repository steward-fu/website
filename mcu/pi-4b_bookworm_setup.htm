安裝


開機後，執行如下命令： 

$ sudo apt-get update
$ sudo apt-get install build-essential git cmake make raspberry-kernel-headers

$ cd
$ git clone https://github.com/goodtft/LCD-show
$ cd LCD-show
$ vim LCD35-show
    # sudo reboot

$ sudo ./LCD35-show
$ sudo apt --fix-broken install
$ sudo ./LCD35-show
$ sudo reboot
