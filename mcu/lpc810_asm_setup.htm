微處理器 - NXP Semiconductors LPC810 - Assembly - 開發環境


LPC810內建BOOT ROM，只要開機進入ISP模式(PIO0_1接GND)，就可以透過UART下載燒錄程式，司徒目前使用lpc21isp燒錄程式，編譯器則是使用GNU GCC，安裝方式如下

編譯lpc21isp燒錄程式 

$ cd
$ wget http://deb.debian.org/debian/pool/main/l/lpc21isp/lpc21isp_1.97.orig.tar.gz
$ tar xvf lpc21isp_1.97.orig.tar.gz
$ cd lpc21isp_197
$ make
$ sudo cp lpc21isp /usr/bin/

安裝GNU GCC編譯器 

$ sudo apt-get install gcc-arm-none-eabi -y
