微處理器 - RDA RDA8810PL (Orange Pi 2G-IoT) - Flash Image(NAND)


參考資訊：
https://www.aib42.net/article/hacking-orangepi-2g

燒錄步驟：
1. NAND Boot Jumper
2. DIP(1~4 ON, 5~8 OFF)
3. 按住Button並插入USB
4. 2秒後放開
5. 執行如下命令 

$ sudo apt-get install python3-serial -y
$ sudo python3 opi2g_nand_write.py -p /dev/ttyACM0 --format-flash --pdl1 pdl1.bin --pdl2 pdl2.bin bootloader:u-boot.rda nandroot:ubi.img
