微處理器 - Allwinner T113-S3 (MangoPi MQ-R) - Assembly - 開發環境


參考資訊：
https://github.com/xboot/xboot/blob/master/docs/guide-allwinner-t113s3.md

司徒的開發環境是Debian 10 x64，使用的編譯工具是GNU GCC，燒錄工具則是使用xfel，安裝步驟如下： 

$ sudo apt-get install gcc-arm* -y

$ cd
$ git clone https://github.com/xboot/xfel.git
$ cd xfel
$ make
$ sudo make install
