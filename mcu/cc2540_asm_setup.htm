微處理器 - TI CC2540 - Assembly - 開發環境


編譯CC-Tool 

$ cd
$ wget https://sourceforge.net/projects/cctool/files/cc-tool-0.26-src.tgz/download
$ mv download cc-tool-0.26-src.tgz
$ tar xvf cc-tool-0.26-src.tgz
$ cd cc-tool
$ ./configure
$ make
$ sudo make install

安裝MCU8051IDE 

$ sudo apt-get install mcu8051ide -y
