微處理器 - Lattice GAL22V10 - C/C++ - 開發環境


司徒使用SDCC作為開發編譯器，燒錄軟體則是使用stcgal 

$ sudo apt-get install python3 python3-setuptools python3-serial sdcc

$ cd
$ git clone https://github.com/grigorig/stcgal.git --recursive
$ cd stcgal
$ ./setup.py build
$ sudo ./setup.py install
$ stcgal --version
    stcgal 1.10
