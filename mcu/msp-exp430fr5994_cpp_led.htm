LED是連接到P1.0


P1 DIR


P1 OUT


Watchdog


PM5


main.c 

#include <stdint.h>
#include <msp430.h>

void delay(uint32_t cnt)
{
    while (cnt--) {
        asm("nop");
    }
}

int main(void)
{
    WDTCTL = WDTPW + WDTHOLD;
    PM5CTL0 &= ~LOCKLPM5;
    P1DIR = BIT0;

    while (1) {
        P1OUT ^= BIT0;
        delay(100000);
    }
}

編譯、下載 

$ msp430-gcc -mmcu=msp430fr5969 main.c -o main.elf
$ mspdebug ezfet 'erase' 'load main.elf' 'exit'
