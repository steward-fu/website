微處理器 - Ingenic JZ4775 (Newton) - Build Kernel


$ cd
$ wget https://github.com/steward-fu/website/releases/download/newton/toolchain_kernel.7z
$ 7za x toolchain_kernel.7z
$ sudo mv newton /opt
$ export PATH=$PATH:/opt/newton/usr/bin

$ wget https://github.com/steward-fu/website/releases/download/newton/src_kernel.7z
$ 7za x src_kernel.7z
$ cd kernel
$ make ARCH=mips newton_defconfig
$ make ARCH=mips -j4 uImage

P.S. arch/mips/boot/compressed/uImage就是燒錄用的Kernel檔案
