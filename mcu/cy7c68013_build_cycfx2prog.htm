微處理器 - Cypress CY7C68013 - Build CycFX2Prog


參考資訊：
https://www.triplespark.net/elec/periph/USB-FX2/eeprom/
https://www.triplespark.net/elec/periph/USB-FX2/software/

步驟如下： 

$ cd
$ wget https://www.triplespark.net/elec/periph/USB-FX2/software/cycfx2prog-0.47.tar.gz
$ tar xvf cycfx2prog-0.47.tar.gz
$ cd cycfx2prog-0.47
$ vim Makefile +12
    $(CC) $(LDFLAGS) cycfx2prog.o cycfx2dev.o -o cycfx2prog -lusb

$ make
