微處理器 - Espressif ESP-32S (NodeMCU-32) - 解決Could not open /dev/ttyUSB0問題


參考資訊：
https://superuser.com/questions/431843/configure-permissions-for-dev-ttyusb0

問題如下： 

Serial port /dev/ttyUSB0

A fatal error occurred: Could not open /dev/ttyUSB0, the port is busy or doesn't exist.
([Errno 13] could not open port /dev/ttyUSB0: [Errno 13] Permission denied: '/dev/ttyUSB0')

Hint: Try to add user into dialout or uucp group.

Failed uploading: uploading error: exit status 2

解法如下： 

$ sudo vim /etc/udev/rules.d/50-embedded_devices.rules
    KERNEL=="ttyUSB[0-9]*", TAG+="udev-acl", TAG+="uaccess"

$ sudo udevadm trigger
