微處理器 - RDA RDA8810PL (Orange Pi 2G-IoT) - Create UBI.img


參考資訊：
https://www.aib42.net/article/hacking-orangepi-2g#fnref5

$ sudo mkfs.ubifs -e 248KiB -m 4096 -c 2000 -r XXX -o nandroot.img
$ vim ubinize.ini
    [nandroot-volume]
    mode=ubi
    image=nandroot.img
    vol_id=0
    vol_name=nandroot
    vol_size=480MiB
    vol_type=dynamic
    vol_alignment=1

$ sudo ubinize -p 256KiB -m 4096 ubinize.ini -o ubi.img
