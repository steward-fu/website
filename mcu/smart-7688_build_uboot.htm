微處理器 - MediaTek MT7688 (LinkIt Smart 7688) - Build U-Boot


參考資訊：
https://docs.labs.mediatek.com/resource/linkit-smart-7688/en/tutorials/firmware-and-bootloader/build-the-bootloader

$ cd
$ wget https://github.com/steward-fu/website/releases/download/mt7688/buildroot-gcc342.tar.bz2
$ tar xvf buildroot-gcc342.tar.bz2
$ sudo mv buildroot-gcc342 /opt
$ export PATH=$PATH:/opt/buildroot-gcc342/bin

$ wget https://github.com/steward-fu/website/releases/download/mt7688/src_uboot.tar.gz
$ tar xvf src_uboot.tar.gz
$ cd uboot
$ make

燒錄(使用USB供電)：
1. 格式化USBDisk成FAT32
2. 複製uboot.bin到USBDisk(lks7688.ldr)
3. 插入USBDisk到MT7688 USB host port
4. 按住WiFi按鈕
5. 20秒後鬆開WiFi按鈕(第二次WiFi LED亮時)
