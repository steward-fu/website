司徒的開發環境是Debian x64，使用的編譯工具是GNU GCC，燒錄工具則是使用xrock，安裝步驟如下： 

$ sudo apt-get install gcc-aarch64* -y

$ cd
$ git clone https://github.com/xboot/xrock
$ cd xrock
$ make -j4
$ sudo make install
