司徒目前使用的編譯器是AVR GNU Compiler，而燒錄軟體則是avrdude，安裝步驟如下： 

$ sudo apt-get install gcc-avr avr-libc avrdude

使用的燒錄器則是AVR USB ISP(如果avrdude不支援，則需要先Patch)
