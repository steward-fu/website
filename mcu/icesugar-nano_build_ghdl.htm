微處理器 - Lattice iCE40LP1K-CM36 (iCESugar-nano) - Build ghdl


參考資訊：
https://github.com/ghdl/ghdl

$ sudo apt-get install llvm llvm-dev clang gnat

$ cd
$ git clone https://github.com/ghdl/ghdl --recursive
$ cd ghdl
$ ./configure
$ make -j4
$ sudo make install
$ ghdl --version
