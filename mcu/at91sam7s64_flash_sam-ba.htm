微處理器 - Microchip AT91SAM7S64 - 如何使用SAM-BA燒錄


參考資料：
http://www.baite-group.com/en/at91/soft-tools.html
https://www.xkwy2018.cn/downloads/J-Link_V8/at91-isp_winxp/Install%20AT91-ISP%20v1.13.exe

進入Bootloader步驟如下：
1. 短路ISP(ERASE連接到3.3V)
2. 連接USB
3. 等待3秒後，斷開USB
4. 斷開ISP(ERASE懸空)
5. 重新連接USB


燒錄步驟如下：
1. 執行SAM-BA並且選擇AT91SAM7S64


2. 載入BIN，按下Send File按鈕


3. 按下Yes按鈕


4. 按下Compare sent file with memory，如果顯示如下訊息，即代表成功，重新上電即可執行燒錄的程式
