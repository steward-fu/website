微處理器 - Microchip ATtiny13 - 解決avrdude: error: program enable: target doesn't answer問題


參考資訊：
https://blog.podkalicki.com/how-to-update-avr-usbasp-firmware-to-latest-version/

加上-B 1024設定bitclock 

$ avrdude -p attiny13 -c usbasp -B 1024 -F -P usb
