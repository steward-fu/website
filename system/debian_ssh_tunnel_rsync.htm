系統 - Debian - SSH Tunnel(rsync)


參考資料：
https://johnliu55.tw/ssh-tunnel.html

在Local建立Tunnel(執行指令後，會提示SSH進Server) 

$ ssh -L 127.0.0.1:9999:192.168.1.27:22 xxx@server_ip

情境：只有Local可以連到Server且只有Server可以連到192.168.1.27:22

Local連接到192.168.1.27 

$ ssh -p yyy@127.0.0.1:9999

P.S. yyy是192.168.1.27帳號

從Local複製資料到192.168.1.27 

$ rsync -auve "ssh -p 9999" test.log yyy@127.0.0.1:/tmp

P.S. 複製Local的test.log到192.168.1.27 /tmp/下
