系統 - Debian - Performance - 如何使用Perf Probe


參考資訊：
https://www.brendangregg.com/perf.html
https://bristot.me/using-perf-probe-to-measure-execution-time-of-user-space-code-on-linux/

hello.c 

#include <stdio.h>

void test(void)
{
    printf("hello\n");
}

int main(int argc, char *argv[])
{
    test();
    test();
    return 0;
}

編譯、執行 

$ gcc hello.c -o hello -ggdb

$ sudo perf probe --line test -x ./hello
    <test@/home/steward/Downloads/hello.c:0>
          0  void test(void)
             {
          2      printf("hello\n");
          3  }
             
             int main(int argc, char *argv[])
             {

$ sudo perf probe -x ./hello 'hello=test:2'
$ sudo perf stat -e probe_hello:* ./hello
    hello
    hello
