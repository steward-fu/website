系統 - Debian - QEMU - 安裝Windows 95 Mini


參考資訊：
https://github.com/Coekjan/winxp-in-qemu

步驟如下： 

$ cd
$ wget https://github.com/steward-fu/website/releases/download/wdm/win95_mini.iso
$ qemu-img create -f qcow2 win95.qcow2 512M
$ qemu-system-i386 -m 64 -drive file=win95.qcow2,index=0,media=disk,format=qcow2 -drive file=win95_mini.iso,media=cdrom,index=1 -boot d
