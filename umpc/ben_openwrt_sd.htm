微電腦 - Ben Nanonote - Install OpenWRT(SDCard)


步驟如下：
1. 準備一張SDCard(partition1: ext2)
2. 在Linux PC上執行 

$ sudo mkfs -t ext2 /dev/mmcblk0p1
$ sudo mount /dev/mmcblk0p1 /mnt
$ cd /mnt/
$ wget https://github.com/steward-fu/website/releases/download/nanonote/openwrt-xburst-qi_lb60-rootfs.tar.gz -O - | sudo tar xz

$ mkdir boot
$ wget https://github.com/steward-fu/website/releases/download/nanonote/openwrt-xburst-qi_lb60-uImage.bin -O boot/uImage

$ wget https://github.com/steward-fu/website/releases/download/nanonote/openwrt-xburst-qi_lb60-root.ubi.bz2
$ bunzip2 openwrt-xburst-qi_lb60-root.ubi.bz2
$ cd
$ sudo umount /mnt/

3. 按住M + Reset鍵開機
