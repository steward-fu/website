微電腦 - SHARP Zaurus SL-C860 - Build Kernel 3.11.3


步驟如下： 

$ cd
$ wget https://github.com/steward-fu/website/releases/download/zaurus/toolchain_for_kernel_3.x.tar.gz
$ tar xvf toolchain_for_kernel_3.x.tar.gz
$ mv toolchain /opt/c860
$ export PATH=$PATH:/opt/c860/bin

$ wget https://github.com/steward-fu/website/releases/download/zaurus/kernel-pxa255_c860_linux-3.11.1.zip
$ unzip kernel-pxa255_c860_linux-3.11.1.zip
$ cd kernel-pxa255_c860_linux-3.11.1
$ ARCH=arm CROSS_COMPILE=arm-none-linux-gnueabi- make c860_defconfig
$ ARCH=arm CROSS_COMPILE=arm-none-linux-gnueabi- make zImage modules -j4
$ INSTALL_MOD_PATH=out ARCH=arm CROSS_COMPILE=arm-none-linux-gnueabi- make modules_install
