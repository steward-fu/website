微電腦 - SHARP Zaurus SL-C3200 - Arch Linux - 解決Coherent pool is too small問題


參考資訊：
https://raspberrypi.stackexchange.com/questions/136076/how-to-edit-coherent-pool-setting-via-cmdline-txt

問題如下： 

ERROR: 256 KiB atomic DMA coherent pool is too small!
Please increase it with coherent_pool=kernel parameter

解法如下： 

在/boot/boot.cfg添加coherent_pool=2M
