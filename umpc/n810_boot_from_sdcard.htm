微電腦 - Nokia N810 - Boot from SDCard


1. 下載https://github.com/steward-fu/website/releases/download/n810/deb_packages.tar.gz
2. 插入SDCard並確定有第2個Partition(ext2)
3. 執行如下指令 

$ tar xvf deb_packages.tar.gz
$ cd n810_bin_debpackages

$ tar zxvf initfs_flasher.tgz
$ cp -a initfs_flasher /

$ sudo cp nupgrade.sh /initfs_flasher
$ cd /initfs_flasher
$ sudo ./initfs_flasher
$ sudo mkdir -p /home/user/bin
$ sudo cp /bin/tar /home/user/bin
$ sudo cp /mnt/initfs/lib/modules/2.6.21-omap1/mbcache.ko /lib/modules/2.6.21-omap1
$ sudo /initfs_flasher/nupgrade.sh wipe
