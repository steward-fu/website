手機 - Unihertz Titan Pocket (TEE) - 如何Root Android


步驟如下：
1. 開啟開發人員選項
2. Settings => System => Advanced => Developer Options => OEM unlocking
3. 執行如下命令： 

$ adb reboot bootloader
$ fastboot flashing unlock
$ fastboot reboot

4. 安裝https://github.com/steward-fu/website/releases/download/titan-pocket/Magisk-v24.1.apk
5. Patch boot.img
6. 重新進入fastboot模式並且燒錄Patched後的boot.img
