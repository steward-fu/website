手機 - F(x)tec Pro1 - Sailfish OS - 如何安裝wget


參考資訊：
https://repo.sailfishos.org/obs/sailfishos:/chum

$ cd
$ curl https://repo.sailfishos.org/obs/sailfishos:/chum/5.0.0.67_armv7hl/armv7hl/sailfishos-chum-gui-0.6.11-1.12.1.bso.armv7hl.rpm --output 1.rpm
$ sudo zypper install 1.rpm

P.S. 開啟Chum GUI並且更新後，即可使用zypper安裝wget
