手機 - Motorola XT897 - Sailfish OS 4.4.0.68 - Debian 12 - 解決This version of the GNU libc requires kernel version 3.2 or later問題


參考資訊：
https://serverfault.com/questions/802747/dist-upgrade-fails-on-libc6-because-kernel-too-old

問題如下： 

Kernel version not supported.
This version of the GNU libc requires kernel version 3.2 or later.
Older versions might work but are not officially supported.
Please consider upgrading your kernel.

解法如下： 

在PC上透過chroot更新libc6
