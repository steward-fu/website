手機 - Cosmo Communicator - Sailfish OS 3.2.1.20 - 安裝系統


參考資訊：
https://www.oesf.org/forum/index.php?topic=36401.0

步驟如下：
1. 必須先安裝Debian系統
2. 進入Debian系統後，執行如下命令 

$ sudo su
# mkdir -p /.stowaways/sailfishos
# cd /.stowaways/sailfishos
# wget https://github.com/steward-fu/website/releases/download/cosmo/sailfishos-cosmocom-release-3.2.1.20-devel-20200211.zip
# unzip sailfishos-cosmocom-release-3.2.1.20-devel-20200211.zip -d rel
# parted /dev/mmcblk0 name 42 SailfishOS
# dd if=rel/hybris-boot.img of=/dev/disk/by-partlabel/SailfishOS
# tar --numeric-owner -xvjf rel/sailfishos-cosmocom-release-3.2.1.20-devel-20200211.tar.bz2
# sync
# reboot

開機後，選擇SailfishOS分區即可進入系統
