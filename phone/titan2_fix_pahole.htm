解法如下： 

$ cd
$ git clone https://github.com/acmel/dwarves.git
$ cd dwarves
$ git checkout v1.30

$ mkdir build
$ cd build
$ cmake ..
$ make -j4
$ sudo make install
$ sudo ldconfig

$ pahole --version
    v1.30
