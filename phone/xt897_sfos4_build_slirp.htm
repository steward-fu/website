手機 - Motorola XT897 - Sailfish OS 4.4.0.68 - Build Libslirp 4.7.0


參考資訊：
https://www.linuxfromscratch.org/blfs/view/12.0/basicnet/libslirp.html

$ cd
$ wget https://github.com/utmapp/libslirp/releases/download/v4.9.1-release-mirror/libslirp-v4.9.1.tar.gz
$ tar xvf libslirp-v4.9.1.tar.gz
$ cd libslirp-v4.9.1
$ mkdir build
$ cd build
$ meson setup --prefix=/usr --buildtype=release ..
$ ninja
$ sudo ninja install
