手機 - Motorola XT894 - Sailfish OS - Debian - 如何安裝Pinta


參考資訊：
https://archive.debian.org/debian-archive/debian/pool/main/p/pinta/

步驟如下： 

$ cd
$ wget https://archive.debian.org/debian-archive/debian/pool/main/p/pinta/pinta_1.6-2_all.deb
$ sudo dpkg -i pinta_1.6-2_all.deb
$ sudo apt --fix-broken install
