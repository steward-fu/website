手機 - Motorola XT897 - Sailfish OS 4.4.0.68 - 解決High cpu usage: tracker-miner-fs-3問題


如果MicroSD檔案太多，Tracker Daemon將會一直佔著CPU，目前解法只能Rename Tracker Process

步驟如下： 

$ cd /usr/libexec/
$ sudo mv tracker-extract-3 __tracker-extract-3 
$ sudo mv tracker-miner-fs-3 __tracker-miner-fs-3
$ sudo mv tracker-miner-fs-control-3 __tracker-miner-fs-control-3
$ sudo mv tracker-xdg-portal-3 __tracker-xdg-portal-3
