手機 - Unihertz Titan (TEE-EMMC) - Debian - 解決libtinfo.so.5 No such file or directory問題


參考資料：
https://packages.debian.org/buster/armhf/libtinfo5/download

解法如下： 

$ echo "deb http://security.debian.org/debian-security buster/updates main" >> /etc/apt/sources.list
$ sudo apt-get update
$ sudo apt-get install libtinfo5 libncurses5-dev
