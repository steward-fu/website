手機 - Unihertz Titan 2 (None-EEA) - Debian - Build QEMU 7.2.0


參考資訊：
https://www.linuxfromscratch.org/blfs/view/11.3/postlfs/qemu.html

$ cd
$ wget wget https://download.qemu.org/qemu-7.2.0.tar.xz
$ xz -d qemu-7.2.0.tar.xz
$ tar xvf qemu-7.2.0.tar
$ cd qemu-7.2.0
$ ./configure --target-list=i386-softmmu,i386-linux-user --enable-virtfs --enable-gtk --enable-slirp
$ ./build/qemu-system-i386 -display gtk xxx.qcow2
