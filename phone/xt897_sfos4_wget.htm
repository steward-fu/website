手機 - Motorola XT897 - Sailfish OS 4.4.0.68 - 如何安裝wget


參考資訊：
https://repo.sailfishos.org/obs/sailfishos:/chum/4.4.0.68_armv7hl/armv7hl/

$ cd
$ curl https://repo.sailfishos.org/obs/sailfishos:/chum/4.4.0.68_armv7hl/armv7hl/sailfishos-chum-gui-0.6.9-1.10.1.jolla.armv7hl.rpm --output sailfishos-chum-gui-0.6.9-1.10.1.jolla.armv7hl.rpm
$ sudo zypper install sailfishos-chum-gui-0.6.9-1.10.1.jolla.armv7hl.rpm

P.S. 開啟Chum GUI並且更新後，即可使用zypper安裝wget
