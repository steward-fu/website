手機 - Motorola XT897 - Sailfish OS 4.4.0.68 - 解決undefined macro: XTRANS_CONNECTION_FLAGS問題


參考資訊：
https://xorg-modular.x.narkive.com/nt7Tpw0z/bug-possibly-undefined-macro-xtrans-connection-flags

問題如下： 

autoreconf: running: /usr/bin/autoconf --force
configure.ac:680: error: possibly undefined macro: XTRANS_CONNECTION_FLAGS
      If this token and others are legitimate, please use m4_pattern_allow.
      See the Autoconf documentation.
autoreconf: /usr/bin/autoconf failed with exit status: 1

解法如下： 

$ sudo zypper install xorg-x11-xtrans-devel
