程式語言 - Node.js - 解決Error: Cannot find module node:path問題


參考資訊：
https://stackoverflow.com/questions/69029896/how-do-you-install-npm-on-ubuntu

問題如下： 

Error: Cannot find module 'node:path'

解法如下： 

$ curl -fsSL https://fnm.vercel.app/install | bash
$ source ~/.bashrc
$ fnm use --install-if-missing 20
