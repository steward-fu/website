程式語言 - Java - Android - SDL v2.0 - 開發環境


編譯環境 

$ java -version
    openjdk version "17.0.17" 2025-10-21

$ sdkmanager --version
    12.0

$ gradle --version
    Gradle 8.2

$ sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"

開發環境 

$ cd
$ git clone https://github.com/steward-fu/sdl2
$ cd sdl2/android
$ ./gradlew assembleDebug -PBUILD_AS_LIBRARY_=true
$ ./gradlew assembleDebug -PBUILD_AS_APPLICATION=true

P.S. 測試的檔案則是修改app/jni/src/main.c
