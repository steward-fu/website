程式語言 - Wine - 解決fatal error: windows.h: No such file or directory問題


參考資訊：
https://forum.winehq.org/viewtopic.php?t=24291

問題如下： 

$ winegcc main.c -o main.exe
    main.c:1:10: fatal error: windows.h: No such file or directory
        1 | #include <windows.h>
          |          ^~~~~~~~~~~
    compilation terminated.
    winegcc: /usr/bin/gcc failed

解法如下： 

$ cd
$ sudo apt-get --build source wine
$ sudo dpkg -i wine*.deb
