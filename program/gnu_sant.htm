參考資訊：
https://hanpfei.github.io/2019/05/19/AddressSanitizer_on_linux/

main.c 

#include <stdio.h>
#include <stdlib.h>
#include <malloc.h>

int main(void)
{
    int *p = malloc(sizeof(int));
    free(p);

    *p = 1000;
    return 0;
}

編譯、執行(沒有fsanitize) 

$ gcc main.c -o main -ggdb
$ ./main

編譯、執行(使用fsanitize) 

$ gcc main.c -o main -fsanitize=address -ggdb
$ ./main
