程式語言 - JavaScript - Build Hermes


參考資訊：
https://github.com/facebook/hermes

$ git clone https://github.com/facebook/hermes.git
$ mkdir hermes/build
$ cd hermes/build
$ cmake ..
$ make -j4
$ sudo make install

$ echo "'use strict'; function hello() { print('Hello World'); } hello();" | ./build/bin/hermes
