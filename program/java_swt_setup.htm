程式語言 - Java - SWT - 開發環境


參考資訊：
https://download.eclipse.org/eclipse/downloads/drops4/R-4.38-202512010920/

步驟如下：
1. 下載 swt-4.38-gtk-linux-x86_64.zip
2. 解開取得swt.jar即可 

$ unzip swt-4.38-gtk-linux-x86_64.zip
$ file swt.jar 
    swt.jar: Java archive data (JAR)

$ cd
$ wget https://download.oracle.com/java/24/latest/jdk-24_linux-x64_bin.tar.gz
$ tar xvf jdk-24_linux-x64_bin.tar.gz -C ~/

$ export JAVA_HOME=~/jdk-24.0.1
$ export CLASSPATH=.:$JAVA_HOME/lib/tools.jar:$JAVA_HOME/lib/dt.jar
$ export PATH=$JAVA_HOME/bin:$PATH
$ java -version
    java version "24.0.1" 2025-04-15
