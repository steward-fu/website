解法如下： 

由於在aarch64上面使用android-studio編譯時，系統會使用x86-64版本的aapt2，因此，需要手動使用aarch64版本覆蓋即可

$ find ~/.gradle/caches -name aapt2 -exec file {} \; | grep x86-64 | awk '{print $1}' | sed 's/://g' | awk '{print "cp ~/android-studio/build-tools/35.0.0/aapt2 "$1}' | sh
