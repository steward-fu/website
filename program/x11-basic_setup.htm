程式語言 - X11-Basic - 開發環境


參考資訊：
https://x11-basic.sourceforge.net/
https://github.com/kollokollo/X11Basic/

$ sudo apt-get install libx11-dev libreadline6-dev liblapack-dev libgmp-dev libfftw3-dev

$ cd
$ git clone https://github.com/kollokollo/X11Basic/
$ cd X11Basic/src
$ ./configure
$ make
$ sudo make install
